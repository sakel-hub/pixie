### 3D Models & Animations (CC-BY-4.0)
- `models/pixie.glb`:
  Based on the original 3D mesh `pixies.b3d` by DuckGo (from ethereal_bosses_reworked, MIT).
  Remastered, re-rigged with articulated fairy wisp armature, vertex weighted, and animated with 13 glTF 2.0 multi-track animation actions (idle, walk, run, fly, attack, hurt, death, flip_back, flip_front, flip_side, flip_side_left, spin_around, somersault) by SaKeL (CC-BY-4.0 / MIT).

### Blender Project Files (CC-BY-4.0)
- `assets/pixie.blend`:
  Original Blender project file containing remastered pixie geometry, articulated armature rig, materials, and NLA animation action tracks by SaKeL. Based on `pixies.b3d` by DuckGo.
- `assets/pixie_poster.blend`:
  High-resolution 3D marketing poster production scene in nature with floral clusters, dynamic lighting, atmospheric environment, and multi-pixie staging authored by SaKeL (CC-BY-4.0).

### Asset Pipeline & Build Automation Scripts (MIT)
Authored by SaKeL:
- `scripts/generate_pixie_particles.py`: Procedural sprite atlas generator for 128x128 particle sheet.
- `scripts/generate_pixie_whistle_texture.py`: Procedural 16x16 pixel-art tool icon generator for the Fairy Whistle.
- `scripts/generate_whistle_sounds.py`: Procedural audio processing and mastering script utilizing Blender LTS `aud` DSP engine.
- `scripts/deploy.mjs`: ContentDB automated release deployment module.
- `scripts/weblate.mjs`: Weblate REST API synchronization module.
